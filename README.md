# JOJO 夢シチュセレクター / YUME SELECTOR

『ジョジョの奇妙な冒険』第1〜7部のキャラクターを複数選択し、夢小説の企画（5本の短いあらすじ）と本編執筆をArgonなどのAIに依頼するためのプロンプトを生成する、非公式ファンメイドWebアプリです。

## 収録内容

- 第1〜7部、主要・準主要・敵キャラなど **計163人** を収録
- 原作で未成年のキャラなどに **「(18歳ver.)」** と表示（年齢設定が不明・資料間で不確かな人物は個別に原作情報を確認してください）
- 部別フィルタ／名前検索／複数選択／お気に入り
- 5人以上の候補から、AIに5人を選ばせてあらすじを出力させるプロンプト
- 5つのあらすじから1本を選んで小説化するためのプロンプト
- シチュエーション・人物関係・文字数・共通指定の編集
- 選択中の候補やお気に入りの自動保存、候補セット保存
- 設定のJSONバックアップ・復元

## 利用方法

1. `index.html` をブラウザで開きます。PCではファイルを直接開いても基本機能を利用できます。
2. 左側のキャラ一覧から、候補を5人以上選びます（スマートフォンでは一覧の下に選択リストがあります）。
3. 「プロンプトを作る」へ進み、ホテルの夜のシチュエーションを使うか、別の設定に書き換えます。
4. 「① あらすじ用をコピー」で生成した文章をArgonに送ります。
5. Argonから返ってきた5案のうち気に入った番号を選び、「② 本文執筆用をコピー」で依頼します。
6. 別のチャットで本編を作るときは、採用するあらすじを「貼り付ける（任意）」欄に入れてください。

## iPhoneでいつでも使うには

**GitHub Pages等のHTTPS対応静的ホスティングに `index.html` を置く** のがおすすめです。追加のビルドは必要ありません。例えば GitHub で新しいリポジトリを作り、ルートに `index.html` を置いて、リポジトリの Pages 設定で公開元を指定すれば、専用URLから使えます。公開先の仕様・設定項目は環境によって異なる場合があります。

SafariでそのURLを開いた後に「ホーム画面に追加」すれば、アプリ感覚で起動できます。iPhoneの「ファイル」アプリからHTMLをプレビューする方式では、JavaScriptやコピー、データ保存の機能が制限される場合があります。

## データ保存とプライバシー

- データは利用中のブラウザの `localStorage` に保存されます。ログイン・外部API・サーバー通信はありません。
- 設定は端末間で同期されません。ブラウザのデータ削除・プライベートブラウズ・URL変更などで失われる場合があります。
- 「データのバックアップ・復元」からJSONを保存・読み込みできます。
- プロンプトは表示・コピーするだけで、アプリからAIへ自動送信しません。
